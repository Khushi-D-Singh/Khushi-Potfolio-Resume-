# Khushi Singh — Developer Portfolio

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive design, theme variables, animations
- `script.js` — typewriter, theme toggle, project filters, detail modal, reveal animations, counters and contact interaction

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Notes
- Bootstrap 5.3.3 and Bootstrap Icons are loaded from jsDelivr CDN; an internet connection is required for those assets.
- The contact form opens the visitor's default email app with a pre-filled message. It does not send or store messages on a server.
- Replace the CSS avatar illustration with a professional portrait if Khushi wants a personal photo.
- CV details are based on the uploaded resume. Project source-code links were not provided, so project cards show details rather than invented repository links.
